# Inter font assets

Self-hosted Inter variable WOFF2 Latin and Vietnamese subsets from
`@fontsource-variable/inter` version 5.2.8, distributed through jsDelivr:

- https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.2.8/files/inter-latin-wght-normal.woff2
- https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.2.8/files/inter-vietnamese-wght-normal.woff2
- License: `OFL.txt` (SIL Open Font License 1.1).

The application uses weights 400, 500, and 600 with `font-display: swap`.
No font download is performed during application build or runtime.
