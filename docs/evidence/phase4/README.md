Visual inspection: neutral dark surfaces, readable status labels, full wrapping addresses/hashes, aligned amounts and mobile navigation. Browser assertions check no document overflow, keyboard Tab/Enter sign-in, visible focus rings and reduced-motion transitions. Inter assets include Latin/Vietnamese coverage and their license. WCAG contrast calculated from the implemented tokens: foreground/surface 14.50:1, muted/surface 7.11:1, primary text/action 17.32:1; status colors/surface all exceed 9:1; input boundary/background 4.04:1. This is focused visual/interaction QA, not a complete accessibility audit.
